webring api

endpoints

GET /api/sites

list all sites (params: ?status=up/broken/dead, ?sort=added_at/click_count/updated_at/name)

POST /api/sites

add new site

GET /api/sites/{name}

get site details

PUT /api/sites/{name}

update site

DELETE /api/sites/{name}

remove site

GET /api/stats

get statistics

GET /api/traffic

get traffic sources

POST /api/check/{name}

check site backlinks (cooldown applies)

rss feeds

GET /feed/new

new sites feed (add ?format=atom for atom format)

GET /feed/updated

recently updated sites feed

GET /feed/status/{status}

sites by status (up/broken/dead)

note on manual status override

set manual_status_override in database to override automatic status checks. This can only be changed directly in the database.
